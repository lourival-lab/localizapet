O Copilot disse
Você pode migrar seu banco do Supabase para o Neon usando ferramentas padrão do PostgreSQL como pg_dump e pg_restore, ou configurar replicação lógica para minimizar downtime. O processo exige atenção às versões do Postgres e às diferenças entre os serviços.

🔑 Métodos de Migração
1. Usando pg_dump e pg_restore (mais direto)
Pré-requisitos:

Projeto ativo no Supabase.

Projeto criado no Neon com a mesma versão do Postgres.

Instalar pg_dump e pg_restore localmente (vem junto com o cliente PostgreSQL).

Passos:

Obtenha os parâmetros de conexão do Supabase:

Host, Database, Port, User, Password.

Execute o dump:

bash


Copiar
pg_dump -Fc -v -d "postgresql://user:password@supabase_host:port/database" --schema=public -f supabase_dump.bak
Restaure no Neon:

bash


Copiar
pg_restore -v -d "postgresql://user:password@neon_host:port/database" supabase_dump.bak
Vantagem: simples e rápido.

Limitação: downtime durante a migração.
neon.com

2. Replicação Lógica (quase zero downtime)
Pré-requisitos:

Supabase com wal_level configurado como logical (já vem habilitado).

Configurar regras de rede no Supabase para permitir conexões dos IPs do Neon.

Usar uma string de conexão direta (não pooled).

Passos:

Habilite o add-on IPv4 no Supabase para obter a conexão direta.

Configure o Neon como assinante da replicação.

Teste a replicação com tabelas de exemplo antes de migrar dados reais.

Vantagem: mantém o banco funcionando enquanto os dados são copiados.

Limitação: configuração mais complexa.
neon.com

3. Migração Completa (Banco + Autenticação)
Se você usa Supabase Auth, também é necessário migrar usuários e políticas de segurança (RLS).

Passos adicionais:

Exportar usuários e hashes de senha do Supabase.

Configurar o Neon Auth.

Importar usuários via script Node.js.

Ajustar IDs e políticas RLS para manter integridade.
neon.com

📊 Comparação dos Métodos
Método	Facilidade	Downtime	Complexidade	Inclui Auth
pg_dump/pg_restore	Alta	Sim	Baixa	Não
Replicação lógica	Média	Quase 0	Média/Alta	Não
Migração completa	Baixa	Variável	Alta	Sim


⚠️ Pontos de Atenção
Versão do Postgres: Neon e Supabase devem estar na mesma versão.

Schemas extras: além do public, o Supabase pode ter dados em auth, storage etc.

Custos: habilitar IPv4 no Supabase pode gerar cobrança adicional.

Testes: sempre faça testes em um banco de staging antes da migração final.

import express from "express";

const app = express();

  connectionString: "postgresql://usuario:senha@host/dbname"
});

// rota para buscar pet por id
app.get("/api/pets/:id", async (req, res) => {
  const { id } = req.params;
  const result = await pool.query("SELECT * FROM pets WHERE id = $1", [id]);
  res.json(result.rows[0]);
});

// rota para atualizar status
app.put("/api/pets/:id/status", async (req, res) => {
  const { id } = req.params;
  const { status, latitude, longitude } = req.body;
  await pool.query(
    "UPDATE pets SET status=$1, latitude=$2, longitude=$3 WHERE id=$4",
    [status, latitude, longitude, id]
  );
  res.json({ ok: true });
});

🐾 Exemplo Backend Minimalista (Node.js)
Crie um arquivo server.js:

js


Copiar
import http from "http";
import { Pool } from "pg";

// Conexão com o Neon
const pool = new Pool({
  connectionString: "postgresql://usuario:senha@host/dbname"
});

const server = http.createServer(async (req, res) => {
  // habilita CORS e JSON
  res.setHeader("Access-Control-Allow-Origin", "*");
  res.setHeader("Content-Type", "application/json");

  // rota GET /pets/:id
  if (req.method === "GET" && req.url.startsWith("/pets/")) {
    const id = req.url.split("/")[2];
    try {
      const result = await pool.query("SELECT * FROM pets WHERE id = $1", [id]);
      res.end(JSON.stringify(result.rows[0]));
    } catch (err) {
      res.statusCode = 500;
      res.end(JSON.stringify({ error: err.message }));
    }
  }

  // rota PUT /pets/:id/status
  else if (req.method === "PUT" && req.url.startsWith("/pets/")) {
    const id = req.url.split("/")[2];
    let body = "";
    req.on("data", chunk => (body += chunk));
    req.on("end", async () => {
      try {
        const { status, latitude, longitude } = JSON.parse(body);
        await pool.query(
          "UPDATE pets SET status=$1, latitude=$2, longitude=$3 WHERE id=$4",
          [status, latitude, longitude, id]
        );
        res.end(JSON.stringify({ ok: true }));
      } catch (err) {
        res.statusCode = 500;
        res.end(JSON.stringify({ error: err.message }));
      }
    });
  }

  else {
    res.statusCode = 404;
    res.end(JSON.stringify({ error: "Rota não encontrada" }));
  }
});

server.listen(3000, () => {
  console.log("Servidor rodando em http://localhost:3000");
});

  res.setHeader("Access-Control-Allow-Origin", "*");
  res.setHeader("Access-Control-Allow-Methods", "GET, POST, PUT, OPTIONS");

    return res.end();

      const result = await pool.query("SELECT * FROM pets ORDER BY id DESC");

    } catch (err) {
      res.statusCode = 500;
      res.end(JSON.stringify({ error: err.message }));

  else if (req.method === "GET" && req.url.startsWith("/pets/")) {

      const result = await pool.query("SELECT * FROM pets WHERE id = $1", [id]);

    } catch (err) {
      res.statusCode = 500;
      res.end(JSON.stringify({ error: err.message }));
    }
  }

  // rota POST /pets (cadastrar novo)
  else if (req.method === "POST" && req.url === "/pets") {
    let body = "";
    req.on("data", chunk => (body += chunk));

      try {
        const { nome, tipo, cor, contato, foto, status, latitude, longitude } = JSON.parse(body);
        const result = await pool.query(

const http = require("http");
const { Pool } = require("pg");

// Conexão com o Neon
const pool = new Pool({
  connectionString: process.env.DATABASE_URL
});

const server = http.createServer(async (req, res) => {
  // habilita CORS e JSON
  res.setHeader("Access-Control-Allow-Origin", "*");
  res.setHeader("Access-Control-Allow-Methods", "GET, POST, PUT, OPTIONS");
  res.setHeader("Access-Control-Allow-Headers", "Content-Type");
  res.setHeader("Content-Type", "application/json");

  // pré‑flight request (CORS)
  if (req.method === "OPTIONS") {
    res.statusCode = 200;
    return res.end();
  }

  // rota GET /pets (lista todos)
  if (req.method === "GET" && req.url === "/pets") {
    try {
      const result = await pool.query("SELECT * FROM pets ORDER BY id DESC");
      res.end(JSON.stringify(result.rows));
    } catch (err) {
      res.statusCode = 500;
      res.end(JSON.stringify({ error: err.message }));
    }
  }

  // rota GET /pets/:id
  else if (req.method === "GET" && req.url.startsWith("/pets/")) {
    const id = req.url.split("/")[2];
    try {
      const result = await pool.query("SELECT * FROM pets WHERE id = $1", [id]);
      res.end(JSON.stringify(result.rows[0]));
    } catch (err) {
      res.statusCode = 500;
      res.end(JSON.stringify({ error: err.message }));
    }
  }

  // rota POST /pets (cadastrar novo)
  else if (req.method === "POST" && req.url === "/pets") {
    let body = "";
    req.on("data", chunk => (body += chunk));
    req.on("end", async () => {
      try {
        const { nome, tipo, cor, contato, foto, status, latitude, longitude } = JSON.parse(body);
        const result = await pool.query(
          `INSERT INTO pets (nome, tipo, cor, contato, foto, status, latitude, longitude)
           VALUES ($1,$2,$3,$4,$5,$6,$7,$8) RETURNING *`,
          [nome, tipo, cor, contato, foto, status, latitude, longitude]
        );
        res.statusCode = 201;
        res.end(JSON.stringify(result.rows[0]));
      } catch (err) {
        res.statusCode = 500;
        res.end(JSON.stringify({ error: err.message }));
      }
    });
  }

  // rota PUT /pets/:id (atualizar status/localização)
  else if (req.method === "PUT" && req.url.startsWith("/pets/")) {
    const id = req.url.split("/")[2];
    let body = "";
    req.on("data", chunk => (body += chunk));
    req.on("end", async () => {
      try {
        const { status, latitude, longitude } = JSON.parse(body);
        await pool.query(
          "UPDATE pets SET status=$1, latitude=$2, longitude=$3 WHERE id=$4",
          [status, latitude, longitude, id]
        );
        res.end(JSON.stringify({ ok: true }));
      } catch (err) {
        res.statusCode = 500;
        res.end(JSON.stringify({ error: err.message }));
      }
    });
  }

  else {
    res.statusCode = 404;
    res.end(JSON.stringify({ error: "Rota não encontrada" }));
  }
});

const port = process.env.PORT || 3000;
server.listen(port, () => {
  console.log(`Servidor rodando em http://localhost:${port}`);
});

No GitHub você pode organizar seus arquivos em pastas da mesma forma que faria no seu computador. Existem duas maneiras principais de criar uma pasta:

🔧 Criando pasta direto no site do GitHub
Vá até o repositório onde você quer criar a pasta.

Clique em Add file → Create new file.

No campo de nome do arquivo, digite o nome da pasta seguido de / e depois o nome de um arquivo dentro dela.

Exemplo: img/pet-default.png ou img/readme.md.

O GitHub vai criar automaticamente a pasta img e colocar o arquivo lá.

Escreva algo no arquivo (mesmo que seja só um comentário) e clique em Commit new file.

🔧 Criando pasta pelo Git (linha de comando)
Se você usa Git localmente:

bash


Copiar
# entrar no repositório
cd nome-do-repo

# criar a pasta
mkdir img

# adicionar um arquivo dentro dela
touch img/readme.md

# adicionar ao git
git add img/readme.md
git commit -m "Criando pasta img com arquivo inicial"
git push
⚠️ Importante: o Git não versiona pastas vazias. Por isso você sempre precisa colocar pelo menos um arquivo dentro (pode ser um readme.md vazio).

✅ No seu caso

async function carregarLista() {
  try {
    const res = await fetch("https://pets-server-8yxb.onrender.com/pets");
    if (!res.ok) throw new Error("Erro ao buscar pets");
    const pets = await res.json();

    const lista = document.getElementById("lista-pets");
    lista.innerHTML = "";

    pets.forEach(pet => {
      const fotoUrl = pet.foto && pet.foto.startsWith("http")
        ? pet.foto
        : "img/pet-default.png";

      const item = document.createElement("div");
      item.className = "pet-item";

          Status: ${pet.status || "Não informado"}<br>
          <a href="detalhe.html?id=${pet.id}">Ver detalhes</a>
        </div>
      `;
      lista.appendChild(item);
    });
